## 2 - Código de repetição da sequência de Fibonacci em linguagem C (sequenciadefibonaccilp.c)
Nesse projeto, desenvolvido com os meus aprendizados na matéria de lógica de programação, são utilizadas diversas estruturas de condição e repetição, além de estruturas de procedimento, para a criação de um algoritmo simples, que mostra ao usuário a sucessão númerica infinita, na qual os dois números anteriores, somados, formam o número subsequente. No desenvolvimento desse projeto, as minhas habilidades acerca das estruturas de condição e repetição na linguagem C foram aplicadas, e meus conhecimentos foram testados para a criação de um programa que atendesse às ações do usuário, e entregasse respostas corretas a cada requerimento.
